## 订阅机制里真正影响你花钱的三个细节

**截止时间**。每周订单有锁定时间：多数配送日的截止时间是下周配送前的周三 11:59 pm（美中时间）；周六、周日配送的订单，截止时间是提前一周的周二 11:59 pm。过了截止时间，那一周的订单就锁定了，不能再跳过或取消。具体时间以你账户里 My Menu 页面显示的为准。

**跳过周**。出差、放假或冰箱满了，在截止前选"skip"那一周就不发货、不扣费。这是很多人不知道但最实用的省钱动作——闲置周不跳过，饭放坏了等于白花钱。
